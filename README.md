# 약속 잡기 (meet)

친구들이랑 약속 날짜 정하는 페이지. https://benny3s.github.io/meet/

- 링크 하나 = 약속 하나 (`?m=<약속id>`). **목록은 어디에도 나오지 않는다** — 링크를 아는 사람만 본다
- 로그인 없음. 들어와서 이름 적으면 바로 참여자가 된다
- 줄 = 사람, 칸 = 날짜, 내용 = 되는 시간 / ✗ / 메모 (밴드매니저와 같은 감각)
- 결과 보기 → 추천 시간 → `정하기` 로 확정

## 구조
- `index.html` — 페이지 한 장 (HTML+CSS+JS). GitHub Pages
- `apps-script.gs` — 서버. Apps Script 웹앱 `/exec`, 저장소는 구글 스프레드시트
  - 시트는 **첫 실행 때 스크립트가 직접 만든다** (스크립트 속성 `SHEET_ID` 에 기억)
  - 탭 6개: 약속 · 설정 · 참여 · 응답 · 메모 · 수정

밴드매니저(`band-manager`)의 캘린더 부분에서 갈라져 나왔다. 배포·캐시·낙관적 반영 규칙은 같다.
